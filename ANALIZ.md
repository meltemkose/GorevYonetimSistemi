# Basit Görev Yönetim Sistemi - Analiz Dokümanı

## Projenin Amacı
Kullanıcıların projeler oluşturabildiği, görev ekleyebildiği ve görevlerin durumunu takip edebildiği web tabanlı bir görev yönetim sistemi geliştirmek.

## Kullanıcı Rolleri
- Admin
- Kullanıcı

## Sistem Özellikleri
- Kullanıcı girişi
- Kullanıcı yönetimi
- Proje oluşturma
- Görev oluşturma
- Görev atama
- Görev durumu güncelleme
- Dashboard
- Arama ve filtreleme

## Kullanılacak Teknolojiler
- ASP.NET Core MVC
- SQL Server
- Git
- GitHub

## Veritabanı Tabloları
- Users
- Projects
- Tasks
